# MATH LAB · 수학 실험실 (포트폴리오 사이트 2차)

직접 만든 수업 게임·교재·앱을 한곳에서 열어 보는 사이트입니다.
방문자는 카드 → **실험 보고서**(설명·수업 활용) → **▶ 실행하기**(사이트 안 전체 화면) 순서로 봅니다.

## 2차에서 바뀐 것
- 가독성: 기본을 밝은 테마로 바꾸고 글자 대비·크기를 키움. 오른쪽 위 ☾ 버튼으로 어두운 테마
- **편집실(`edit.html`, 오른쪽 위 EDIT)**: 비밀번호로 들어가 사이트에서 바로 **링크 추가·수정·숨기기·삭제·순서 바꾸기**
  - 저장 장소는 선생님의 **구글 시트**(Apps Script, 무료). 저장하는 순간 모든 방문자에게 보임
  - 큰 제목·소개 문장도 '사이트 정보' 탭에서 바꿈

```
2차 개발/
├─ index.html, style.css, app.js   방문자 화면
├─ edit.html, edit.css, edit.js    편집실
├─ store.js                        구글 시트 연결
├─ apps-script/Code.gs             구글 시트에 붙여 넣을 코드 (편집실 안내가 비밀번호를 넣어 줌)
├─ data/works.js                   처음부터 있던 작품 목록 (사이트 파일)
├─ data/sheet-config.js            ★ 구글 시트 웹 앱 주소 (처음 한 번 채움)
├─ works/, thumbs/                 사이트 파일로 된 작품·그림
└─ 작품 모으기.ps1                  최신 차수를 works/로 다시 복사
```

## 1. GitHub Pages로 올리기 (웹에서만)
1. GitHub → **+** → **New repository** → 이름 `아이디.github.io`(주소가 가장 깔끔) → **Public** → Create
2. **uploading an existing file** → 이 폴더 **안의 내용**을 끌어다 놓기 → Commit
   (한 번에 100개 넘으면 `works` 안 폴더를 나눠서 올리기. `작품 모으기.ps1`은 안 올려도 됨)
3. **Settings → Pages** → Deploy from a branch → **main / (root)** → Save → 1~2분 뒤 주소가 뜸

## 2. 편집실 켜기 (처음 한 번, 약 10분)
올린 사이트에서 **EDIT**를 누르면 4단계 안내가 나옵니다.
1. 편집 비밀번호 정하기 → 안내 화면이 코드에 넣어 줌
2. 새 구글 시트 → 확장 프로그램 → Apps Script → 코드 붙여 넣고 저장
3. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → 권한 승인 → **웹 앱 URL** 복사해 안내 화면에 붙여 넣기
4. 안내 화면이 만들어 준 내용으로 GitHub의 `data/sheet-config.js` 바꾸기 (✎ → 붙여 넣기 → Commit)

그다음부터는 **EDIT → 비밀번호 → 편집**만 하면 됩니다.

## 3. 알아 두기
- **새 자료는 링크로** 올려요. GitHub Pages·넷리파이·패들렛·구글 드라이브(링크 공유 켜기)·유튜브 등 `https://` 주소면 돼요.
- **HTML 작품을 새로 올리고 싶을 때**: GitHub 저장소의 `works/` 폴더에 올리거나(Add file → Upload files) 작품별 저장소를 따로 만든 뒤, 그 주소를 편집실에서 링크로 추가하세요.
- **사이트 파일로 된 작품**(처음 8개)은 편집실에서 고쳐도 원래 파일은 그대로이고, 고친 부분만 시트에 저장돼요. **되돌리기**로 원래대로, 지우기 대신 **숨기기**.
- **비밀번호 바꾸기**: Apps Script 코드 맨 위 `PASSWORD`를 고치고 저장 → 배포 → 배포 관리 → 연필 → 버전 '새 버전' → 배포 (주소는 그대로).
- 비밀번호를 10번 틀리면 10분 동안 저장이 막혀요.
- 시트를 직접 고치지는 말고 편집실에서 고쳐 주세요. 실수하면 구글 시트의 '버전 기록'으로 되살릴 수 있어요.
