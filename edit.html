// SETUP — 처음 한 번만

편집실 준비하기

편집한 내용은 선생님의 구글 시트에 저장되고, 저장하는 순간 모든 방문자에게 보여요. 아래 순서대로 한 번만 설정하면 됩니다. (약 10분, 무료)

  1. 편집 비밀번호 정하기

    편집실에 들어올 때 쓸 비밀번호를 정해 주세요. 8자 이상, 다른 사이트에서 쓰지 않는 것으로요.

  2. 구글 시트에 코드 붙여 넣기

    새 구글 시트를 만들고 이름을 MATH LAB 편집실로 바꿔요.
    위쪽 메뉴 확장 프로그램 → Apps Script → 열린 창의 글을 모두 지우고 아래 코드를 붙여 넣기 → 💾 저장.

    코드를 불러오는 중…

    1단계에 비밀번호를 적으면 코드 맨 위에 자동으로 들어가요.

  3. 웹 앱으로 배포하기

    Apps Script 창 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택
    · 다음 사용자 인증 정보로 실행: 나
    · 액세스 권한이 있는 사용자: 모든 사용자
    → 배포 → 액세스 승인 → 구글 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 고급 → (안전하지 않음)으로 이동 → 허용.
    마지막 화면의 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사해 아래 칸에 붙여 넣으세요.

    '확인하지 않은 앱' 경고는 선생님이 직접 만든 코드라서 나오는 거예요. 이 코드는 이 시트 하나만 읽고 써요.

  4. 사이트에 연결하기

    아래 내용을 복사해서, GitHub 저장소의 data/sheet-config.js 파일을 열고 → 연필(✎) → 내용을 모두 바꿔 붙여 넣기 → Commit changes.

    (3단계 칸을 채우면 여기에 만들어져요)

    1~2분 뒤 이 페이지를 새로 고치면 비밀번호 입력 화면이 나와요.

    어떤 링크를 올릴 수 있나요?

    • GitHub Pages·넷리파이에 올린 내 작품, 패들렛, 구글 문서·슬라이드, 유튜브 등 https:// 로 시작하는 주소는 모두 돼요.
    • '사이트 안에서 바로 보기'를 켜면 방문자가 이 사이트를 떠나지 않고 볼 수 있어요. 안에서 안 열리는 곳(구글 로그인이 필요한 앱, 네이버 블로그 등)은 끄면 새 탭으로 열려요.
    • 구글 드라이브 파일은 공유 → 링크가 있는 모든 사용자로 바꾼 뒤 링크를 붙여 넣으세요.

    원래 사이트 파일에 있던 작품

    제목·설명 등을 고치면 구글 시트에 '고친 내용'만 저장되고 원래 파일은 그대로예요. 되돌리기를 누르면 처음 상태로 돌아가요. 지우기 대신 숨기기가 있고, 숨긴 작품은 언제든 다시 보이게 할 수 있어요.
